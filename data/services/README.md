## Scope and practical limits

- **Repairs and mechanics:** customer reception/counter access is separate from access to a workshop floor. A service-vehicle yard is not automatically wheelchair parking. IT Solvz adds a computer-repair location alongside vehicle mechanics. No pickup, home service or vehicle-transfer assistance is inferred.
- **Pharmacies:** a parking or entrance label does not establish the aisle/counter route or counter height. MedActiv Victoria and Trianon are official branch identities with access unknown. Cascavelle's parking label may concern shared mall parking; no dedicated pharmacy bays are confirmed.
- **Hospitals/clinics/doctors:** a building label does not establish access to a specific consultation room, examination table, imaging equipment or department. transfer_support and accessible_equipment remain unknown. A doctor's practice does not automatically inherit the containing clinic's features.
- **MIOT:** the operator describes adapted restrooms with grab bars and a wheelchair-friendly lift. The news report does not resolve the current street address here; confirm the premises before planning a visit.
- **FCDO identity records:** the facility/practitioner directory is dated 21 October 2024. Current practice locations, appointments and access need reconfirmation. These records do not certify current licensing, clinical suitability or service availability.
- **Victoria Hospital:** official information establishes the Candos site, not universal access to all wards/services. No department-specific wheelchair audit was performed.

No medical advice, clinician ranking or treatment recommendation is supplied. This is a physical-access research dataset. No field inspections, telephone checks or direct accessibility-review verification were performed.

| Level | Meaning |

| directory_labels_only | Third-party accessible feature labels. |
| unknown | Identity/location known but physical access unestablished. Does not mean inaccessible. |

Feature status listed_yes means directory only. In step_free_entrance it is an accessible-entrance label, not measured proof of no steps. Parking scope branch_listing_scope_unresolved leaves ownership/location uncertain. No venue is certified fully accessible, and an ordinary toilet is not an adapted toilet.

## CSV files and Power BI

| File | Grain | Key |
| --- | --- | --- |
| [services.csv](services.csv) | One researched branch/practice | service_id |
| [accessibility_observations.csv](accessibility_observations.csv) | One scoped claim/research gap | observation_id |
| [sources.csv](sources.csv) | One source page | source_id |
| [Mapped services.csv](../osm/services.csv) | Existing OSM place object filtered to explicit repair/healthcare categories | record_id |

Import UTF-8 comma-delimited CSV. Set last_web_check and checked_date to Date, field_verified to True/False, and other researched fields to Text. For mapped data retain numeric coordinates and nullable bay counts per the OSM dictionary.

For researched evidence, relate services[service_id] (1) to accessibility_observations[service_id] (*) and sources[source_id] (1) to accessibility_observations[source_id] (*), single-direction. Keep parent_service_id as identity context or use a separate parent query; no feature inheritance. Use a separate source query for identity metadata to avoid ambiguous active relationships.

Use service_type/region/accessibility_level filters. Count distinct service_id for researched entries. The mapped view may overlap shops, office or other views and the researched entries. Do not sum these tables as unique venues or append the mapped subset back into the national inventory.

## Research field dictionary

| Fields | Meaning |
| --- | --- |
| service_id, service_name, service_type | Stable branch/practice key, name and type. Preserve IDs on rename. |
| locality, region, address | Sourced location with uncertainty explicit. |
| accessibility_level, wheelchair_access | Evidence category and broad physical-access status. |
| step_free_entrance, wheelchair_parking, wheelchair_toilet, lift | Individually supported features only. |
| parking_scope | unknown or branch_listing_scope_unresolved; no shop-owned bays inferred. |
| service_room_access, accessible_counter | Route to actual consultation room/service desk and usable counter; currently unknown. |
| transfer_support, accessible_equipment | Specific patient/customer assistance or equipment; currently unknown. |
| parent_service_id | Practice's containing facility identity where supported; not access inheritance. |
| identity_source_id, contact_url | Public provenance/follow-up link. |
| last_web_check, field_verified, notes | Retrieval date, field-inspection flag and limits. |

Observation columns: observation_id, service_id, feature, status, source_id, scope, checked_date and summary. Unknown observations record research gaps rather than source claims that access is absent. Sources record source_id, title, url, evidence_type and checked_date.
